    string status = isExcellent ? "Отличник" : "Хорошист";

#ОТВЕТЫ НА ВОПРОСЫ

1.Метод Console.Write() выводит текст в консоль и оставляет курсор на той же строке — следующий вывод продолжится сразу после предыдущего текста. Метод Console.WriteLine() выводит текст и автоматически добавляет символ перевода строки — курсор перемещается на новую строку. Это удобно для структурированного вывода отдельных сообщений.

2.При попытке присвоить переменной типа int дробное значение (например, int x = 3.14;) компилятор выдаст ошибку времени компиляции: невозможно неявно преобразовать тип double в int. Чтобы сохранить только целую часть, нужно явно привести тип: int x = (int)3.14; (результат — 3). Для сохранения дробной части следует использовать тип double.

3.В C# деление двух целых чисел (int / int) всегда даёт целочисленный результат — дробная часть просто отбрасывается. Чтобы получить дробный результат, нужно привести хотя бы один операнд к типу с плавающей точкой: (double)10 / 3 или 10.0 / 3. Тогда результат будет 3.333….


4.Ключевое слово var в C# позволяет компилятору автоматически вывести тип переменной на основе присвоенного значения (например, var x = 3.14; → тип double). При этом C# остаётся статически типизированным языком: тип определяется на этапе компиляции и не может измениться в ходе выполнения. В Python используется динамическая типизация: тип переменной определяется во время выполнения и может меняться (например, сначала x = 3.14 (float), потом x = "text" (str)).
